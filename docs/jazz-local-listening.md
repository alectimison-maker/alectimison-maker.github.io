# Jazz 本地音频接入

此版本已于 2026-10-28 发布到现有阿里云服务器，保留专辑头图、封套与黑胶播放器设计。本地未完成原型未纳入发布。

## 资源导入

```bash
npm run import:jazz -- /path/to/jazzy
```

导入器仅访问 `albums/` 与 `sources/stantard/` 中的资源，不使用原项目的前后端实现。专辑按标题正规化后匹配网站已有记录，匹配不到或存在歧义的专辑不自动加入。前缀曲序（`01 So What`）与中/英文括号后缀曲序均被识别；输出音频使用稳定的 ASCII 文件名，保留 Unicode 曲名与原始 M4A 内容。

本次匹配 9 张专辑、86 首曲目、27 张相关图片。原目录不修改，现有网站封面不替换；导入封面作为资源保留。`public/jazz-local/` 被 Git 忽略，源路径和音频二进制不写入代码仓库。

另已导入 `sources/stantard/` 的 15 组标准曲、305 个演奏版本及 305 张对应原图，支持 M4A/MP3。运行 `npm run import:jazz` 会一并更新专辑与标准曲；只更新散曲可运行 `npm run import:jazz:standards -- /path/to/jazzy`。音频使用相同的被忽略目录，生成索引 `src/data/jazz-standards.json`。高清封面使用下面的站点统一媒体流程。

不同演奏者、不同目录版本不合并；字节完全相同的音频共用文件。标准曲 Miles Davis / So What 与已有专辑第一首相同，复用已有地址；原图片仍单独保留。空版本目录跳过。`All Of Me/17` 内文件实际名为 All Of Us（Paul Whiteman），保留文件曲名并在列表标记待核对；不擅自把它改为 All Of Me。原目录中的 Take The A Rain 拼写同样保留。

## 本地页面

- `/jazz/`：保持原收藏展示；专辑可进入独立页面，搜索包含已导入曲名，分类栏显示专辑数与可播曲目数。
- `/jazz/albums/<id>/`：原有专辑舞台与黑胶外观，接入播放/暂停、切歌、进度、音量、顺序连播，下方展示有序曲目及相关影像。所有唱片均不展示外部音乐链接或第三方嵌入播放器。
- `/jazz/<category>/`：只展示专辑及 Standard 封面卡片、搜索和曲名筛选，没有播放器或音频元素。
- `/jazz/standards/<id>/`：独立演绎详情页，沿用专辑的头图舞台和原黑胶播放器。进入后点击才加载音频；可切换同一标准曲的前后版本并返回原分类。
- `?track=<track-id>`：可定位某张专辑中的曲目，加载页面不会自动出声。

## 全站播放与历史

专辑/曲目黑胶播放器与全站侧边悬浮球共用 `src/lib/music-player.ts` 的唯一音频实例；实例独立于页面组件，不在组件卸载时暂停。`BaseLayout.astro` 使用 Astro ClientRouter，悬浮球以 `transition:persist` 保留；Jazz 按钮跳转也使用 Astro `navigate()`。文章、分类、搜索、联系页及 404 的 DOM 绑定适配了换页生命周期，离页时清理页面监听器/观察器，避免切页后原有功能失效。

全站提供液态玻璃悬浮球，无播放记录时显示音乐图标；封面圆形、播放时旋转，暂停时保持当前角度。点击向左展开扁平播放条（0.55 秒），紫色进度条与无阴影的深色玻璃播放键；可播放/暂停、切歌、调整进度/音量、返回当前曲目页或查看最近播放。尊重系统减少动态效果设置。封面使用压缩缩略图，不在全站导入整个音频目录或标准曲全集。

当前浏览器的 localStorage 保存当前队列、曲目、进度、音量和最近 20 首播放记录；每 5 秒及暂停/页面退出时保存，支持历史曲目续播和清空历史。不跨设备同步。重新打开或刷新只恢复界面和位置，不请求音频或自动出声；点击继续播放。正常站内导航不断音，刷新/关闭页面会结束当前音频实例，之后可从保存位置继续。

验证包括：4 项共享音频状态/历史测试（单实例、顺序连播、进度/音量、恢复时不加载/不自动播放、历史续播、无效记录处理），以及浏览器实测专辑→Article 连续播放、悬浮球切歌、刷新恢复到 0:50、暂停时停止旋转。

曲目分类先继承网站已有的专辑分类，这是现有收藏的整理规则，并未重新判断每首歌的音乐流派。未匹配到本地音频的唱片仅展示封面与唱片信息，不提供外部音乐链接、嵌入播放器或音源提示。

标准曲以主题分组建立初始浏览标签，对明确的演唱者和部分演奏者增加辅助标签；规则保存在 `scripts/jazz-standard-utils.mjs`。这些是可调整的收藏归档，不把曲名或演奏者等同于每个版本的严格音乐流派。散曲和专辑使用同样的封面卡片形式，支持按曲名、主题、演奏者搜索，点击封面进入实际曲目详情，不生成虚构专辑链接。

## 高清封面与加载速度

原文件夹的 305 张图片只有 130px（301 张）或 177px（4 张），因此导入时不放大仍会在卡片中模糊。`npm run restore:jazz-covers -- /path/to/jazzy` 已按原图片 ID 恢复全部 305 张同款高清原图，并通过缩小后的内容比较确认封面一致；原图范围 320–4096px，268 张至少 600px，不使用 AI 重绘封面文字。

重复封面合并为 292 个源文件，位于 `src/assets/media/images/jazz/standards/`。恢复脚本直接运行本站现有的 `scripts/optimize-images.mjs`，统一生成按实际尺寸限制的 480/960/1600/2560 档 WebP，以及 960px 以上的 AVIF；不为小图制造放大的变体。网页根据屏幕宽度与像素密度选择文件，保留懒加载和异步解码，列表不请求高清原始 JPEG。`JazzCover.tsx` 与 Astro 的 `ResponsiveImage.astro` 共用媒体 manifest 和编码参数。小卡片优先使用 480px WebP，避免因 AVIF 最小为 960px 而下载过大文件；详情页使用 AVIF/WebP 响应式变体。292 个去重封面的最小变体中位数为 25.64 KiB，全部新增压缩变体共 118.32 MiB。重复运行媒体优化时，新增生成数为 0，沿用现有缓存。

导入器会检查高清来源记录并继续沿用统一媒体源，重新导入音频不会把已恢复的封面降回 130px。分辨率与内容核对记录在 `src/data/jazz-cover-quality.json`；原始 `jazzy` 文件不修改。

### 空队列随机续播

队列为空时点击播放，以及当前队列已播完/末尾点击下一首时，按需读取 `/jazz/audio-library.json`，从全库 390 个独立音频中随机选一首继续。索引来自已导入专辑与 Standard，按音频地址去重；有其他曲目时排除刚播放的同一音频。索引在当前浏览器页面会话内缓存，音频只请求选中那一首。首次访问不会自动选歌/出声。

手动选曲会取消未完成的随机选择，防止慢网络响应覆盖用户选择；索引读取失败显示重试提示，不循环重试。新增 4 项测试覆盖空队列按需播放、队列耗尽随机续播及不重复、手动选择优先和失败重试。浏览器验证空队列→Moyu→随机下一首 So What 正常播放。
